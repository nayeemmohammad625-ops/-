# 🛺 3D Rickshaw Rush - ৩ডি রিকসা গেম (PWA)

একটি মোবাইল-ফ্রেন্ডলি ৩ডি কার্টুন রিকসা সিমুলেশন গেম যা সম্পূর্ণ HTML5 Canvas, Three.js এবং React দিয়ে তৈরি। গেমটিতে রয়েছে বাংলাদেশি গ্রামীণ ও শহরের মেঠোপথ, হাইওয়েতে পুলিশ পেট্রোল, বাস-ট্রাকের ট্রাফিক, রিকসার টুং-টাং ঘণ্টা, যাত্রী পরিবহন এবং অ্যাক্সিডেন্টে রাগী জনতার কার্টুন এনিমেশন।

---

## 🎮 গেমপ্লে ফিচারসমূহ (Gameplay Features)

1. **যাত্রী পরিবহন ও ভাড়া (Passenger Rides):** রাস্তার পাশে দাঁড়িয়ে থাকা যাত্রীদের কাছে গতি ধীর করে দাঁড়ালে যাত্রী ওঠে। সোনালী আলোকস্তম্ভ ও নির্দেশক তীরের দিকে চালিয়ে গন্তব্যে পৌঁছালে দূরত্ব ও সময়ের ওপর ভিত্তি করে ভাড়া ও বোনাস টিপস পাওয়া যায়।
2. **যানবাহন ও ট্রাফিক (Traffic Simulation):** রাস্তায় ঢাকা লোকাল বাস, মালবাহী ট্রাক, প্রাইভেট কার ও সিএনজি অটোরিকশা চলে।
3. **হাই রোড ও ট্রাফিক পুলিশ (Highway & Police):** হাইওয়েতে রিকসা নিষিদ্ধ! হাই রোডে উঠলে পুলিশ সাইরেন বাজিয়ে তাড়া করবে ও জরিমানা করবে। জরিমানা এড়াতে গ্রামের মেঠোপথ বা সরু গলি দিয়ে ঘুরে যেতে হবে। টাকা শেষ হলে ব্যাংকরাপ্ট গেম ওভার!
4. **অ্যাক্সিডেন্ট ও রাগী জনতা (Accident & Angry Crowd):** গাড়ি বা বাসের সাথে ধাক্কা লাগলে কার্টুন স্টাইলে রাগী জনতা ছুটে এসে রিকসা ঘিরে ফেলে।
5. **৩টি ডিফিকাল্টি মোড (Easy, Medium, Hard):**
   - **সহজ (Easy):** কম ট্রাফিক, ৩টি জীবন (Lives), কম জরিমানা।
   - **মাঝারি (Medium):** মাঝারি ট্রাফিক, ২টি জীবন, সতর্ক পুলিশ।
   - **কঠিন (Hard):** দ্রুতগতির ঘন ট্রাফিক, ১টি জীবন, কড়া জরিমানা।
6. **লেভেল ১ থেকে ১০ (Levels 1 to 10):** প্রতি লেভেলে আয়ের টার্গেট (৳৪০০ থেকে ৳৬০০০) পূরণ করলে পরবর্তী লেভেল আনলক হয়। প্রগ্রেস ও হাই-স্কোর ব্রাউজারের `localStorage` এ সেভ থাকে।
7. **দ্বিভাষিক UI (Dual Language):** এক ক্লিকে বাংলা এবং ইংরেজিতে সুইচ করা যায়।
8. **সাউন্ড সিন্থেসাইজার (Web Audio Procedural Sound):** কোনো অডিও ফাইল ডাউনলোড ছাড়া সরাসরি রিকসার টুং-টাং পিতলের ঘণ্টা, সাইকেল চেইনের আওয়াজ, ট্রাকের হর্ন ও পুলিশের সাইরেন বাজে।

## 🚀 GitHub এ পুশ ও GitHub Pages এ হোস্ট করার গাইড

### ধাপ ১: গিট ইনিশিয়ালাইজ ও কমিট করুন
আপনার টার্মিনালে প্রজেক্ট ফোল্ডারে গিয়ে রান করুন:
```bash
git init
git add .
git commit -m "Initial commit: 3D Rickshaw Rush PWA"
```

### ধাপ ২: গিটহাব রিপোজিটরির সাথে যুক্ত করে পুশ করুন
GitHub.com এ গিয়ে একটি নতুন পাবলিক রিপোজিটরি তৈরি করুন (যেমন: `rickshaw-rush-3d`), তারপর:
```bash
git branch -M main
git remote add origin https://github.com/<আপনার-ইউজারনেম>/rickshaw-rush-3d.git
git push -u origin main
```

### ধাপ ৩: GitHub Pages চালু করুন (অটোমেটিক PWA ডেপ্লয়মেন্ট)
1. আপনার GitHub রিপোজিটরির **Settings** ট্যাবে যান।
2. বাম পাশের মেন্যু থেকে **Pages** এ ক্লিক করুন।
3. **Build and deployment** সেকশনের **Source** ড্রপডাউনে **GitHub Actions** সিলেক্ট করুন।
4. যেহেতু `.github/workflows/deploy.yml` ফাইলটি ইতিমধ্যে যুক্ত আছে, গিটহাব নিজে থেকেই প্রজেক্টটি বিল্ড করে একটি লাইভ লিংক দিয়ে দিবে (যেমন: `https://<আপনার-ইউজারনেম>.github.io/rickshaw-rush-3d/`)।

## 📱 মোবাইলে অ্যাপের মতো ইন্সটল করার নিয়ম (PWA)

1. **Android (Chrome):**
   - ব্রাউজারে লিংকটি খুলুন।
   - গেমের উপরে থাকা **"অ্যাপ ইন্সটল করুন"** বাটনে চাপ দিন (অথবা ক্রোম মেনু থেকে **Add to Home Screen** চাপুন)।
   - মোবাইলের হোম স্ক্রিনে অ্যাপ আইকন চলে আসবে এবং ইন্টারনেট ছাড়াও অফলাইনে সম্পূর্ণ স্মুথলি চলবে।

2. **iOS (iPhone / Safari):**
   - সাফারি ব্রাউজারে লিংকটি খুলুন।
   - নিচে থাকা **Share** আইকনে চাপ দিন।
   - স্ক্রোল করে **Add to Home Screen** এ চাপ দিন।
